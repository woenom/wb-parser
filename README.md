## Проект стягивания данных

Данный проект при развёртывании на сервере стягивает данные и помещает в таблицы. Включает в себя скрипты парсинга 'WbApiParsing' и 'WbParsingService'. Для корректной работы сервиса необходимо в '.env' поставить значение ключа 'WB_API_KEY' на примере, как в '.env.example'. Изменение других значений не требуется, но есть возможность изменения через 'config/services' в 'wb'.

## Принцип работы

Каждую минуту сервер запускает скрипт 'WbApiParsing'. В нём формируются значения запросов. Далее запускается функция 'parseEndpoint', находяющаяся в 'WbParsingService'. В нём уже производится запрос в базу данных. Стягивается только 25 страниц из-за ограничения по времени команды. Таким образом все 500 страниц проверяется за 20 циклов и после полной обработки, циклы начинают работать по новой.
